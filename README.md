# 바로합계

상품 바코드로 상품을 구분하고, 가격 QR/바코드 또는 직접 입력으로 단가를 등록하여 수량과 합계를 자동 계산하는 모바일 웹 MVP입니다.

## 실행

카메라는 보안상 `HTTPS` 또는 `localhost`에서만 동작합니다. 이 폴더에서 간단한 로컬 서버를 실행한 뒤 휴대폰/브라우저로 접속하세요.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 카메라 인식은 `BarcodeDetector`를 지원하는 Chrome 또는 Edge에서 가장 잘 동작합니다. 미지원 브라우저에서는 상품 스캔 기능을 사용할 수 없습니다.

## 휴대폰에 앱처럼 설치

이 프로젝트는 PWA로 구성되어 있습니다. HTTPS 주소에 배포한 뒤 Android Chrome에서는 `앱 설치`, iPhone Safari에서는 공유 메뉴의 `홈 화면에 추가`를 선택합니다. 설치 후 기본 화면과 장바구니 계산은 오프라인에서도 열립니다. 행사표 OCR은 최초 언어 데이터 다운로드 등에 인터넷 연결이 필요할 수 있습니다.

GitHub 저장소의 `main` 브랜치에 올리고 Settings → Pages → Source에서 `GitHub Actions`를 선택하면 포함된 워크플로가 HTTPS 사이트를 자동 배포합니다.

## 백업과 내보내기

`지출 한눈에 보기`의 데이터 관리 영역에서 전체 데이터를 JSON 파일로 백업하거나 다시 가져올 수 있습니다. 가져올 때 기존 데이터와 합치거나 백업으로 모두 교체할 수 있습니다. `선택 월 CSV`는 조회 중인 달의 날짜, 상품명, 품목, 단가, 수량, 행사와 최종 금액을 UTF-8 CSV로 저장합니다.

## 사용 흐름

1. 상품 바코드를 스캔합니다.
2. 처음 보는 상품이면 상품명과 단가를 입력합니다. 가격 코드를 따로 읽으려면 `가격 코드 스캔` 버튼을 누릅니다.
3. 등록된 상품 바코드를 다시 스캔할 때마다 수량과 합계가 1개씩 증가합니다.
4. 같은 상품이 여러 개면 해당 상품을 선택하고 수량을 숫자로 한 번에 입력할 수 있습니다. `+`/`-` 버튼으로도 조절할 수 있습니다.
5. 마지막으로 스캔한 상품에 행사표를 적용하려면 `행사표 사진 인식`을 누르고 사진을 촬영합니다.

행사 사진에서는 `1+1`, `2+1`, `2개 3,000원`, `20% 할인`, `500원 할인` 형식을 자동 판별합니다. OCR 결과는 적용 전에 수정할 수 있습니다. 사진의 글자 인식은 브라우저에서 실행되는 Tesseract.js를 사용하며, 최초 이용 시 인터넷 연결이 필요합니다.

## 날짜별 지출 기록과 대시보드

장바구니에서 이용 날짜를 선택하고 `지출 기록 저장`을 누르면 해당 브라우저에 구매 내역이 저장됩니다. `지출 한눈에 보기`에서 조회 월을 바꾸면 월간 총지출, 장보기 횟수, 구매 수량, 최다 구매상품, 최근 6개월 추이, 품목별 지출, 자주 산 상품과 날짜별 내역을 확인할 수 있습니다. 기록은 서버가 아닌 브라우저 `localStorage`에만 보관됩니다.

가격 QR은 `2200`, `PRICE:2200`, 또는 `{"price":2200}` 형식을 지원합니다. 상품 정보는 해당 브라우저의 `localStorage`에 저장됩니다.
